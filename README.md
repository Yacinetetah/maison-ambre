# Maison Ambre — Boutique de parfums

Site vitrine e-commerce de parfums, en HTML / CSS / JavaScript pur (aucune dépendance).

## Fonctionnalités
- Catalogue de 12 parfums (femme, homme, mixte) avec flacons dessinés en CSS
- Filtres, recherche par nom ou par note olfactive, tri par prix / popularité / nom
- Fiche produit : pyramide olfactive, choix de la contenance (30 / 50 / 100 ml)
- Panier latéral sauvegardé dans le navigateur (localStorage), livraison offerte dès 80 €
- Responsive (mobile, tablette, desktop)

## Lancer en local
Ouvrir `index.html` dans un navigateur.

## Mise en ligne
Le site est publié avec GitHub Pages (Settings → Pages → branche `main`, dossier `/ (root)`).
